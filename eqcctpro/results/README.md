# Results Directory

This directory stores all artifacts generated by EQCCTPro runs and evaluations.

## Structure
- `csv/`: Contains the primary benchmarking results (`gpu_test_results.csv`, `cpu_test_results.csv`).
- `csv/logs/`: Contains detailed execution logs and prediction outputs:
    - `eval_cpu_eqcct/`: Logs and station-specific predictions from CPU trials.
    - `eval_gpu_eqcct/`: Logs and station-specific predictions from GPU trials.
    - `eqcctpro.log`: The aggregate log file for the latest run.

## Output Types
1. **Performance Metrics**: CSV files summarizing throughput and resource utilization. For detailed descriptions of the CSV columns, see the [Main README](../README.md#understanding-evaluation-results-csv-columns).
2. **Prediction Results**: `X_prediction_results.csv` files containing P/S wave arrival picks for each station.
